# ATLAS

**AI Systems & Automation**

Public website and technical portfolio for ATLAS, an independent AI systems and automation studio founded by Kristie McCready.

## Purpose

This site serves two audiences: hiring teams evaluating Kristie for full-time AI automation, implementation, systems and solutions roles, and businesses looking for select consulting engagements.

## Stack

- React
- TypeScript
- Vite
- CSS design system
- Planned deployment: Cloudflare

## Status

Early build. Project visuals, portrait, contact details, resume, LinkedIn and GitHub presentation links are intentionally pending rather than fabricated.

## Principles

- Build around real business operations
- Show real work without exposing confidential information
- Do not invent metrics or outcomes
- Accessible, responsive and performance-conscious
- Keep the codebase understandable and reviewable
